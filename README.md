# Учебный frontend-проект: Хэллоуинский магазин SpookyShop

## Описание
Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».
Тема проекта: интерактивный многостраничный интернет-магазин праздничного декора и костюмов SpookyShop, выполненный в качестве Контрольной работы №1.

## Структура проекта (5 физических страниц)
- `index.html` — Главная страница сайта (hero-блок, преимущества, витрина из 9 популярных товаров);
- `catalog.html` — Полный каталог товаров (двухколоночная Grid-раскладка, фильтры и сетка из 18 товаров);
- `product.html` — Карточка товара (развернутая информация о костюме скелета с таблицей характеристик);
- `order.html` — Оформление заказа (5-я страница маркетплейса с интерактивным выпадающим списком всех 18 товаров);
- `contacts.html` — Контакты (информация шоурума, встроенная живая Яндекс Карта и форма обратной связи);
- `css/style.css` — Единый файл стилей с БЭМ-архитектурой и дизайн-токенами;
- `js/main.js` — Файл скриптов для управления модальным окном обратного звонка;
- `sitemap.xml` — Простая карта сайта для поисковых систем.

## Постановка контрольной работы №1
Тема контрольной работы №1: «HTML и CSS: разработка многостраничного сайта».
В рамках контрольной работы разработан полноценный многостраничный HTML/CSS-сайт интернет-магазина.
Проект включает в себя:
- главную страницу с интерактивным баннером и правилами Хэллоуина;
- страницу каталога с сеткой товаров и блоком фильтрации;
- страницу карточки товара с подробными техническими характеристиками;
- страницу оформления заявки (официальная 5-я физическая страница);
- страницу контактов с реальными демонстрационными данными и встроенной интерактивной картой;
- семантическую HTML-разметку;
- интерактивные неоновые состояния элементов при наведении и фокусе.

## Реализованные элементы интерфейса
- Кнопки «Подробнее» на всех карточках каталога для перехода к описанию товара;
- Полноценная страница заказа с выбором любого из 18 хэллоуинских товаров;
- Живая интерактивная Яндекс Карта, центрированная по сетке сайта;
- Всплывающее модальное окно «Заказать обратный звонок» на JS (дополнительный балл за Практическую №3);
- Базовая HTML/JS-валидация форм, защита от серверной ошибки 405 (перевод на метод GET).

## БЭМ-структура проекта
В проекте используются следующие БЭМ-блоки:
- `site-header` — шапка сайта;
- `site-nav` — лаконичная основная навигация на 5 вкладок с плашками активности;
- `breadcrumbs` — хлебные крошки;
- `hero` — первый экран главной страницы;
- `products-grid` — сетка товаров;
- `product-card` — карточка товара;
- `catalog-layout` — структура страницы каталога;
- `catalog-filters` — фильтры каталога;
- `order-dialog` — модальное окно обратного звонка;
- `order-form` — формы заявок;
- `button` — кнопка;
- `site-footer` — прижатый к низу экрана подвал сайта.

## Использование Flexbox и Grid
- **Flexbox:** управление шапкой, центрирование элементов меню навигации, внутренняя структура карточек товаров, выравнивание чекбоксов согласия и флекс-прижим подвала к нижней границе экрана ПК;
- **CSS Grid:** сетка карточек на главной и в каталоге (`repeat(3, 1fr)`), двухколоночный макет страницы каталога (`260px 1fr`).

## CSS-архитектура
- CSS-переменные в `:root` (дизайн-токены палитры, скруглений и адаптивных отступов);
- Единая шкала промежутков `gap` и отступов;
- Интерактивные состояния `:hover`, `:focus-visible`, `:disabled`;
- Фиксированный многослойный задний фон (эффект Parallax с паутиной).
